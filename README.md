# 光路偵探｜十一站互動實驗室

不只背成像口訣，讓學生自己移動物體，看光怎麼走。

## 使用方法

1. 打開網站，選擇一個單元。
2. 先寫下預測：像在哪裡、正倒、大小，光屏接不接得到？
3. 用滑桿調整條件；凸透鏡站亦可拖動物體與光屏。
4. 顯示光路證據，觀察實際交會或反向延長線交會。
5. 補寫解釋、完成小測並閱讀原因回饋；需要時匯出文字紀錄。

可切換教師投影模式及光路大圖模式。建議電腦與教室投影；平板觸控尚未實機驗證。

## 實際單元

核心五站：光的直進／針孔成像、平面鏡、折射、凸透鏡、凹透鏡。

延伸六站：凹凸面鏡、三稜鏡色散、眼睛／眼鏡、相機、望遠鏡、顯微鏡。
全反射併在折射站內，標為延伸內容。

每站提供真實影響圖像的互動控制；不同單元控制方式不同，不是每站都有拖曳。
眼睛、相機及雙鏡片儀器以近軸光線傳遞模型計算，並於畫面明示限制。

## 離線與隱私

免費使用、免登入；可下載 `index.html` 用一般瀏覽器離線開啟，無CDN依賴。
本作品程式不蒐集學生資料、不主動傳送紀錄，預測與解釋只存在本次頁面記憶體；
關閉前請自行匯出。GitHub託管本身可能有平台存取紀錄，參考網站連結需網路。

## 教學與科學限制

康軒國中程度教學取向，但未取得正式教材逐頁核對，不是康軒官方教材；請依授課冊次確認。
透鏡、曲面鏡及儀器為理想薄透鏡／近軸簡化，垂直獨立放大以利追光，不能量圖上角度；
反射、折射及色散角度單元使用等比例座標。圖外光線或像會裁切，請對照數值提示。
未模擬像差、繞射、亮度、有限口徑、真實瞳孔與臨床視力；眼鏡示意不是醫療配鏡處方。
三稜鏡使用明示的Cauchy示意模型，不代表特定材料實測。眼睛與儀器不供精密設計用途。

## 測試

使用Node執行：

```
node test-convex.cjs
node test-extra.cjs
node test-advanced.cjs
```

通過5501原版檢查、204組物高光線案例、2599項延伸檢查及3095項新儀器檢查。
包含焦點、2f、臨界角、凹凸眼鏡矯正、兩鏡片與無窮遠邊界；另檢查JS語法、DOM及無外部依賴。
程式測試不等於瀏覽器視覺驗收；平板觸控與各設備投影仍請課前試用。
