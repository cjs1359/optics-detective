十一站實驗室

基礎五站，加上面鏡、全反射／色散、眼睛／眼鏡、相機、望遠鏡與顯微鏡。延伸站採近軸簡化模型，先猜再用光路驗證。

光學台

光由左向右。拖動圖下方的物體或光屏把手；也可用下方滑桿。圖的垂直方向獨立放大以分離光線，不能直接從圖上量角度。藍色鏡片固定在中央。

主光線 1：橘色平行入射 → 過後焦點　｜2：藍色過光心不偏折　｜3：紫色沿前焦點方向入射 → 平行射出。
實線是真實光路；虛線只代表反向延長，不是光往回走。箭頭標出光前進方向。

薄透鏡：1/f = 1/u + 1/v；放大率 m = −v/u。
實物 u > 0；本實驗 f > 0。v > 0 為實像，v < 0 為虛像；m < 0 為倒立。焦距、物距、像距使用相同單位。

① 先預測

物體先放在 2F 外。暫時不顯示像，先說說你的想法。

預測以按下按鈕時的情境為準；之後可以自由拖動。

② 找到證據

  1. 按「再畫一條」逐條看光走哪裡。
  2. 開啟「像與延長線」。
  3. 拖光屏，看能否接到清晰實像。
  4. 切到 u = f 和 u < f，比較光路。

問自己：「是光線真的相交，還是只有延長線相交？」

③ 用一句話解釋

因為折射後的光線＿＿，所以形成＿＿像；光屏＿＿接到。

④ 小測與回饋

選一個答案，看看光路證據。

時間教學行動可直接說
0–5 分放大鏡看近處文字、想像遠處倒像同一片凸透鏡，為什麼有時正、有時倒？

37–45 分一句話解釋、小測、口頭分享口訣是結果，光路才是原因。
模型與限制
這是薄透鏡、近軸成像示意，不模擬球面像差、繞射、亮度、有限口徑或真實眼睛視野。光線代表來自物體頂端的作圖用代表光線，實際有無數條。為讓光路可讀，圖中射線可能超出鏡片造型；鏡片畫法是位置符號，不是物理口徑。u = f 時折射光平行，沒有有限位置的像；接近焦點時像可能在畫面外。光屏清晰提示採像距 ±2% 或 ±0.15 cm 的操作容許值，不是景深計算。光屏預覽只提示聚焦，不模擬失焦影像。圖的水平尺度依物距調整，垂直固定為 65 圖像單位／cm（兩軸不等比例），方便追蹤光線；不能用圖面量角度，位置與成像比值請以數值為準。增大物高僅用來觀察成像趨勢，仍採理想薄透鏡近軸模型。
光線顏色表示作圖規則，不表示不同波長；並以 1、2、3 文字區分，避免只靠顏色辨識。

小測

教師引導：先問「你猜光會往哪裡走？」再顯示證據。「哪一段是真光線？哪一段只是延長線？用一句話說出依據。」新增單元使用滑桿而非圖上拖曳。康軒冊次深度仍待授課教材核對。
